About Me

I’m a Network Administration student in Montreal with hands-on experience designing and building enterprise-style labs. I’ve configured Windows Server (AD DS, DNS, DHCP, Exchange), deployed Linux services (Apache, Samba, Bind, NFS), and automated tasks with PowerShell, Bash, and Ansible.

In my lab projects, I’ve set up multi-site Active Directory forests, secured pfSense firewalls with VPNs, simulated enterprise networking on Cisco routers and switches (VLANs, OSPF, ACLs, NAT), and deployed infrastructure on VMware Workstation. I’ve also worked with Zabbix monitoring, RAID storage, and backup strategies to improve reliability.

I’m currently expanding into cloud technologies by deploying VMs, services, and applications on AWS, Microsoft Azure, and Google Cloud Platform (GCP). My cloud labs include setting up DNS, SSL, load balancers, VM templates, and Kubernetes clusters.

My strengths are in network infrastructure, system reliability, and documenting step-by-step processes, and I’m eager to apply this knowledge in a networking or cloud internship role.
