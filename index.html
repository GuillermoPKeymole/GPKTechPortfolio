About Me

I'm a Network Administration student based in Montreal with hands-on experience configuring Windows Server, Linux (AlmaLinux & Ubuntu), and automating tasks with PowerShell & Bash.

I’ve deployed and managed secure Active Directory forests, set up multi-site Exchange Server environments, and built end-to-end enterprise networks using Cisco routers and switches in GNS3 with routing protocols, VLANs, and NAT.

My strengths lie in infrastructure design, system reliability, and creating detailed documentation. I'm currently exploring AWS and Azure as I advance toward a junior systems or cloud administrator role.
